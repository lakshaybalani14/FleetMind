# FleetMind Dashboard - Quick Start

## 3 Steps to Running

1. `npm install`
2. `npm run dev`
3. Open http://localhost:3000

## What You'll See

- 4 Status Tiles (Gas, Temp, Actuator, Connectivity)
- Telemetry Chart (Gas/Temperature trends)
- Action Log (Event trace)
